# Launcher Icons for Manhwa Reader Extension

Since Aniyomi extensions typically use the default launcher icon, you can:

1. **Use the default**: Aniyomi will use a default icon for your extension

2. **Create custom icons**: If you want custom icons, create PNG files in these folders:
   - `src/en/manhwareader/res/mipmap-hdpi/ic_launcher.png` (72x72 px)
   - `src/en/manhwareader/res/mipmap-mdpi/ic_launcher.png` (48x48 px)
   - `src/en/manhwareader/res/mipmap-xhdpi/ic_launcher.png` (96x96 px)
   - `src/en/manhwareader/res/mipmap-xxhdpi/ic_launcher.png` (144x144 px)
   - `src/en/manhwareader/res/mipmap-xxxhdpi/ic_launcher.png` (192x192 px)

3. **Quick solution**: You can copy icons from any existing Aniyomi extension as a placeholder.

For now, the extension will work without custom icons - Aniyomi will display a default icon.
